# Registro de decisiones de arquitectura (ADR)

Las decisiones D-01 a D-09 están resumidas en `docs/spec/01-arquitectura.md`. Cualquier decisión
nueva o cambio a una existente se registra aquí como `NNNN-titulo.md` con esta plantilla:

```markdown
# NNNN — Título

- Estado: Propuesta | Aceptada | Reemplazada por NNNN
- Fecha: AAAA-MM-DD

## Contexto
## Opciones consideradas
## Decisión
## Consecuencias
```
